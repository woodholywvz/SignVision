# SignVision MVP

Сайт для распознавания заранее заданных фраз РЖЯ по короткой видеозаписи. OpenCV декодирует видео; MediaPipe Tasks извлекает 21 точку каждой руки и 33 точки тела. Для каждого кадра сохраняются положение рук относительно плеч, форма кисти относительно запястья и координаты верхней части тела. DTW сравнивает последовательности с учётом траектории и скорости, kNN выбирает фразу. Запись с маленькой долей кадров с руками, далёкая от всех примеров или неоднозначная запись получает ответ «Неизвестный жест».

## Запуск

Нужен Python 3.11–3.13. Из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m signvision.models
uvicorn signvision.web:app --reload
```

Откройте [http://localhost:8000](http://localhost:8000). Браузеру нужен доступ к камере. Сайт записывает жест через `MediaRecorder` и отправляет видео серверу. Также можно загружать готовые MP4/WebM/MOV/AVI. После обработки видео удаляется; в `data/` сохраняются только ключевые точки в `.npz`. Фразы и пороги задаются в `config.yaml`; после их изменения перезапустите сервер. Ошибки записываются в `logs/errors.log`.

Интерфейс доступен на русском и английском: переключатель RU/EN находится в шапке, выбор сохраняется в браузере и в параметре `?lang=ru` или `?lang=en`. Русская форма фразы задаётся полем `text`, английский перевод — необязательным полем `en` в `config.yaml`. Если перевода нет, показывается русский текст. API локализует результат и ошибки по заголовку `Accept-Language` (`ru` или `en`).

Начните с нескольких записей каждой фразы от разных людей. Выберите фразу перед сохранением записи. Блок проверки принимает отдельные, ещё не добавленные в датасет видео и показывает точность по всем загруженным файлам. Можно добавить метку «Неизвестный жест» для проверки отказа от неизвестного класса. Эти тестовые записи не сохраняются в обучающий датасет. Для реальной оценки держите людей и условия съёмки независимыми от обучающих примеров.

Список фраз в поставке служит конфигурацией интерфейса, а не готовой обученной моделью. Порог `max_distance` и `min_margin` нужно откалибровать на своих независимых видео. Прототип принимает один жест на запись и не переводит непрерывную речь.

```powershell
pytest -q
```

Модели скачиваются из [официального хранилища MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/python) при выполнении `python -m signvision.models` и остаются в игнорируемой Git папке `models/`.
