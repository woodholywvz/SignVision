# SignVision

SignVision — сайт для изучения и распознавания **фиксированных фраз русского жестового языка**. Он сравнивает короткую запись с загруженными эталонами и показывает фразу, осторожную подсказку или «Неизвестный жест». Это сравнение последовательностей, а не обучаемая нейросеть и не перевод непрерывной жестовой речи. Точность на реальных жестах пока не измерена.

## Возможности

- Отслеживание суставов рук и верхней части тела поверх камеры в реальном времени, в том числе **во время записи**.
- Запись одного жеста с камеры или загрузка видео. Сохраняются положение кистей относительно плеч, конфигурация пальцев и движение между кадрами.
- Классификация DTW + kNN, отказ от далёких и неоднозначных жестов, подсказки при умеренном сходстве.
- Управление фразами и эталонами с автором и датой каждого нового примера; проверка качества на независимых видео.
- Уроки, тренировка, личный прогресс; администратору доступны список пользователей, их прогресс и назначение ролей.
- Русский и английский интерфейс, светлая и тёмная темы, вход через ChatGPT и по почте с паролем.

## Две версии приложения

| | Локальная версия | Публичный сайт ChatGPT Sites |
| --- | --- | --- |
| Код | `signvision/`, `static/` | `site/`, `static/ui-refresh.css` |
| Обработка видео | Python, OpenCV, MediaPipe Tasks | MediaPipe Tasks Vision в браузере |
| Отслеживание суставов | WebSocket `/api/track` | Локально в браузере |
| Эталоны | `.npz` в `data/` | Нормализованные последовательности в R2 |
| Профили и прогресс | Нет | D1 |
| Распознавание | DTW + kNN на сервере | DTW + kNN в Worker |

У версий разные датасеты и настройки: локальный [`config.yaml`](config.yaml) не меняет публичный сайт, а [`site/config.json`](site/config.json) не меняет локальную Python-версию. Исходные видеозаписи эталонов в облаке не сохраняются. Для первой загрузки моделей MediaPipe нужен доступ к сети.

## Запуск локальной версии

Нужны Python 3.11–3.13, веб-камера и браузер с поддержкой `MediaRecorder`.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m signvision.models
uvicorn signvision.web:app --reload
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Разрешите камеру, выберите фразу и запишите несколько коротких примеров. Можно загрузить MP4, WebM, MOV или AVI. Видео временно обрабатывается и удаляется; в `data/` остаются только ключевые точки. Ошибки пишутся в `logs/errors.log`.

Фразы и пороги задаются в `config.yaml`; после изменения перезапустите сервер. Для английского перевода используйте необязательное поле `en`. Интерфейс переключается в шапке, API выбирает язык по `Accept-Language`.

Для проверки суставов нажмите «Проверить суставы» на вкладке распознавания. Зелёные линии и точки показывают руки, синие — тело. Проверка не добавляет кадры в датасет. Сервер принимает JPEG-кадры по WebSocket и отправляет следующий кадр только после обработки предыдущего; частота зависит от устройства.

## Разработка версии Sites

Нужен Node.js с поддержкой Web Crypto. Из корня проекта:

```powershell
npm ci
npm test
npm run build
```

`npm test` собирает Worker и выполняет тесты с временной SQLite-базой; опубликованные D1 и R2 не затрагиваются. `npm run build` создаёт `dist/`: статические файлы, Worker, конфигурацию хостинга и миграции D1. Структура базы находится в [`db/schema.ts`](db/schema.ts), миграции — в [`drizzle/`](drizzle/). Миграция `0002` **только добавляет** таблицы почтовых реквизитов и сессий; существующие аккаунты и прогресс не удаляются.

При смене домена добавляйте его к существующему проекту из [`.openai/hosting.json`](.openai/hosting.json), а не создавайте новый проект: там уже находятся профили, уроки и эталоны. На новом домене пользователю может понадобиться снова войти, поскольку cookie привязан к имени хоста; профиль и прогресс остаются в D1.

## Аккаунты и роли

Первый профиль администратора создаёт владелец, вошедший через ChatGPT с адресом `BOOTSTRAP_ADMIN_EMAIL`. После этого остальные могут регистрироваться по почте; новые почтовые профили всегда получают роль ученика. Действующий пользователь ChatGPT может добавить пароль **к тому же аккаунту** на странице профиля. Его уроки и прогресс останутся общими для обоих способов входа. Повторная регистрация с занятым адресом не создаёт второй профиль. Администратор назначает роли через список пользователей.

Пароли хранятся как PBKDF2-SHA256 с индивидуальной случайной солью, в D1 хранится только хеш токена сессии. Сессионный cookie имеет атрибуты `HttpOnly`, `Secure`, `SameSite=Lax` и действует 30 дней. После пяти неверных попыток вход блокируется на 15 минут. **Подтверждения почты и восстановления пароля пока нет**: сохраните пароль; для владельца вход через ChatGPT остаётся резервным.

Добавлять и удалять фразы, эталоны и материалы уроков могут только администраторы. У нового эталона сохраняются автор и время загрузки. Старые примеры не удаляются; если автор раньше не записывался, он показан как неизвестный.

## Эталоны и оценка

Соберите несколько записей **каждой** фразы от разных людей, с разным освещением и ракурсами. Одна запись должна содержать один жест. В Sites видео эталона ограничено 8 секундами. Пять исходных фраз заданы в `site/config.json`; администратор может добавить до 30 новых. Доступно до 25 эталонов на фразу и до 300 всего. Дополнительные фразы хранятся в D1 и появляются в уроках и распознавании без изменения кода.

Не используйте одни и те же записи для обучения и оценки. В разделе «Проверка точности» загрузите отдельные видео, желательно других людей или условий. Метка «Неизвестный жест» позволяет проверить отказ от чужих жестов. Тестовые видео не добавляются в эталоны. По результатам подберите `max_distance`, `tentative_distance` и `min_margin` в конфигурации Sites. Добавление эталона сразу меняет набор сравнения; веса MediaPipe не обучаются.

Если жест совсем не похож на эталоны, выводится «Неизвестный жест». При пограничной дистанции или неоднозначности сайт показывает «Возможно, вы имели в виду…» и совет. Пороги эвристические: для реального использования их нужно проверить на независимом наборе видео.

## Проверки

```powershell
pytest -q
node --test tests/tracking.test.cjs
npm test
```

Python-тесты проверяют извлечение и нормализацию точек, отсутствие рук и записи разной длины. Клиентские тесты проверяют очистку точек и поздние ответы при остановке отслеживания. Тесты Sites проверяют сохранение и распознавание эталонов, отказ от далёкого жеста, уроки, роли администратора, почтовые сессии и привязку пароля к профилю. Они подтверждают работу кода, но не измеряют точность на реальном РЖЯ.

## Ограничения

- Распознаётся один заранее известный жест на короткую запись; непрерывный перевод пока не реализован.
- Нужны видимые руки и достаточно кадров. Закрытые кисти, плохой свет и резкие повороты снижают качество.
- Советы при неуверенном распознавании не гарантируют правильной классификации.
- До набора и независимой проверки эталонов нельзя утверждать, что система надёжно распознаёт РЖЯ.

Модели локальной версии загружаются из [официального хранилища MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/python) командой `python -m signvision.models` и остаются в игнорируемой Git папке `models/`.
